# Code Kernel '26 — Prototype submission checklist

## Required fields in Unstop

- [ ] **GitHub repository URL:** create a new public repository named `pathwise-code-kernel` (or another available name), then upload the contents of this folder. Do not upload `node_modules`.
- [ ] **Demo video URL:** record a 3-minute walkthrough using `DEMO_SCRIPT.md`; upload to YouTube as Unlisted or Google Drive with access set to “Anyone with the link”.
- [ ] **Architecture / flow diagram:** upload `architecture.png` (PNG is explicitly accepted by the form).
- [ ] **Deployed URL:** optional. Only enter a URL after the live site has been tested in a private/incognito browser.

## Before recording

1. Run `npm install` and `npm run dev`.
2. Verify the Learn → Solve → Test flow for Ananya.
3. Switch to Aarav and confirm the lesson changes to extension mode.
4. Open Teacher dashboard and verify the differing recommendations.
5. Run `npm run build` and `npm run test`.
6. Reset demo data before recording.

## Important honesty checks

- The learner profiles and scores are sample data.
- The included content is sample English content, not a verified NCERT/state-board curriculum.
- The current version uses local browser storage and has no backend or multi-device sync.
- Do not claim a public repository, deployed application or recorded video until those steps are completed and tested.
