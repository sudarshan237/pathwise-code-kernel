# PathWise — 3-minute demo script

**0:00–0:20 | Problem**  
“In a typical classroom, students learn at different speeds, but they often receive the same lesson and the same practice. PathWise demonstrates a way to adapt the next learning step while keeping the teacher in control.”

**0:20–1:10 | Student experience: learner who needs foundations**  
“Here is Ananya, a Class 7 learner. Her current sample mastery in fractions is 38%. The system selects a scaffolded explanation rather than pushing her into a harder lesson. She moves through Learn, Solve and Test. After the checkpoint, the system updates her mastery using both prior evidence and the latest result.”

**1:10–1:45 | Student experience: learner ready to advance**  
“Now I switch to Aarav. His sample mastery is 88%. The same topic now presents an extension explanation and a transfer-oriented next step. The content path changes because the learner signal changes.”

**1:45–2:35 | Teacher dashboard**  
“The teacher sees a class snapshot, learners who may need foundations, learners ready for extension, and suggested next actions. These are recommendations, not automatic decisions. The teacher remains responsible for interpreting student work and choosing the intervention.”

**2:35–3:00 | Architecture and limitations**  
“The prototype uses React and TypeScript, a transparent rule-based adaptation engine, and browser-local storage. This version uses sample English curriculum content and demo profiles. A real school rollout would require board-aligned content, reviewed translations, more assessment evidence, educator validation and secure multi-user storage.”

## Recording checklist

- Record the app full-screen in a browser at desktop width.
- Show Ananya at 38% mastery and Aarav at 88% mastery.
- Complete one Learn → Solve → Test path so the score update is visible.
- Open the Teacher dashboard and show the differentiated recommendations.
- Do not describe sample data as real student data or claim production deployment.
